# Mahir Velizade Portfolio — Project Context

## Goal
Maintain and optimize Mahir Velizade's portfolio site at https://mahirvelizade.space/

## Tech Stack
- Single-page HTML/CSS/JS (no framework)
- YouTube IFrame API (music player)
- THREE.js (3D model)
- Web Speech API (TTS + speech recognition)
- Hosted on GitHub Pages, custom domain via Namecheap

## Key Files
- `index.html` — Main portfolio (1235 lines, was 2046): Home, Work, About, Contact, inline JS
- `style.css` — All styles extracted from index.html (cacheable)
- `mahir_qa.js` — Q&A pairs + AI chat widget DOM generation + chat logic
- `3D.glb` — 3D model rendered with THREE.js
- `mysite.md` — Changelog of all changes made (#1–#12)
- `CNAME` — Custom domain config
- `.opencode/agent.md` — This file

## Optimizations Applied
- CSS extracted to `style.css` (was inline, ~800 lines)
- AI chat DOM now generated by `mahir_qa.js` (not hardcoded in HTML)
- Fonts loaded asynchronously (`media="print"` swap)
- Work images use `loading="lazy"`
- Matrix canvas uses `requestAnimationFrame` instead of `setInterval`
- Google Fonts preconnect for faster load
- Index.html reduced from 2046 → 1235 lines (~40% smaller)
